# IZOLYATSIA Xmas Archive

Static site, deployed by Netlify from `main`: it serves `public/` as-is (see `netlify.toml`). Output is committed; there is no build step on Netlify — run `make build` locally and commit the result.

Each year is a hand-made legacy page in `public/YYYY/index.html`. The parts shared by all pages (title, social meta tags, year nav, prev/next arrows, credits) and the home page card grid are generated by `build.py` from `years.json`. The script only rewrites what sits between marker comments and never touches anything else.

| Slot | Where | Content |
| --- | --- | --- |
| `<!-- @title -->` | year pages | `<title>` |
| `<!-- @head -->` | year pages, home | meta/og/twitter tags, `nav.js`, `nav.css` (year pages) |
| `<!-- @nav -->` | year pages | year nav, prev/next arrows, arrow-key script |
| `<!-- @credit -->` | inside the page's `.credit` element | its inner HTML (`credit` in `years.json`) |
| `<!-- @credit_bottom -->` | 2012 only | second credit |
| `<!-- @cards -->` | home | card grid |

Pages with no credit (2022, 2025) have no credit slot. Credit slots sit inside each page's own markup, so placement and styling stay page-specific.

## Commands

    make build     # python3 build.py: regenerate slots (stdlib only)
    make images    # python3 build.py --images: thumbnails (Pillow) + share images (node + Playwright)
    make check     # python3 build.py --check: verify, change nothing, exit 1 on problems

`build.py` is idempotent: a second run changes nothing.

## Add a year (e.g. 2027)

1. `python3 build.py --new 2027` creates `public/2027/index.html` from `templates/year.html` (or copy your own page and add the slots by hand).
2. Put the postcard next to it (`public/2027/postcard.jpg`) and design the page. Delete the `.credit` line if the year has no credit.
3. Add an entry to `years.json`:

       {"year": 2027, "description": "Postcard by …", "credit": "Postcard by …", "thumb": "2027/postcard.jpg"}

   Fields: `description` (meta/og text), `credit` / `credit_bottom` (inner HTML), `video` (badge on the card), `thumb` (source image for the thumbnail; `thumb_crop` e.g. `"3:2"`, `thumb_fit: "cover"`), `card_bg` (card background, filled in automatically by `make images` when missing, set it by hand to override), `collage` (`"cover"`/`"contain"` to include it in the home share image).
4. `make images` (thumbnail, share image, card colour), then `make build`, then `make check`.
5. Commit `years.json`, `public/`.

Adding a year updates every other page automatically: nav, the previous year's next arrow, and the "2011–2027" range in descriptions.

`--images` needs Pillow and Node with Playwright and Chromium preinstalled. Plain `make build` needs neither.
